安装帮助

这是什么

把 Google TV / Chromecast 蓝牙遥控器变成 Windows 的「按住说话 + 快捷键」设备： 语音键按住说话（发给输入法），其余按键映射成键盘 / 鼠标 / 文本命令。

第一次使用（4 步）

1. 双击程序文件夹里的 「一键安装.bat」（弹一次 UAC 点「是」）—— 自动建开机自启任务并启动；
2. Windows 设置 → 蓝牙和其他设备：添加设备，配对你的遥控器；
3. 左键点托盘图标（或本页地址）打开设置页，在「设置」页选择你的遥控器，保存；
4. 按住遥控器语音键说话试试（输入法需要把麦克风设为「CABLE Output」）。

虚拟声卡（语音功能必需）

语音走「遥控器 → VB-CABLE 虚拟声卡 → 输入法」链路，需要虚拟声卡 VB-CABLE：
· 安装包已内置驱动文件，程序以管理员运行时会自动检测并静默安装；
· 若被安全软件拦截或自动失败：到「语音」页点「检测并安装」（弹一次 UAC）；
· 仍不行就手动运行 %ProgramData%\VibeMate\vbcable\VBCABLE_Setup_x64.exe。

按键映射

「按键映射」页 → 学习模式：按遥控器任意键，给它配一个键盘 / 鼠标 / 文本动作。
出厂默认：方向键=方向键，OK=回车，返回=退格（长按连删），主页=ESC， 输入=Shift+Tab，电源 / YouTube / Netflix=Ctrl+回车发送 /exit、/clear、commit+push， 音量=Ctrl+滚轮，语音键=Win+Ctrl 按住说话。

托盘

左键：打开设置页；右键菜单：设置 / 重启 / 退出。
重启 = 自动卸载按键注入、释放蓝牙会话，再拉起新实例重新挂载 —— 注入或蓝牙出怪问题时先点它。
图标动效：待机=闭眼呼吸；按到有映射的键=快闪一轮；语音输入=声浪循环。

排障

· 一切异常先看「日志」页（对应程序目录 vibe.log；[CABLE] 段是虚拟声卡安装流水）；
· 蓝牙连不上：遥控器休眠了，按任意键唤醒再等几秒；
· 按键没反应：看状态页「按键」通道是否「已连接」，未连接先点托盘「重启」；
· 完整卸载：删除程序目录 + 任务计划程序里的 VibeMate 任务 + %ProgramData%\VibeMate。
